## What is it

A diagram that starts from a single central topic and branches outward into subtopics, then further sub-branches, using short keywords, images, and lines rather than sentences — a tree structure built to mirror how ideas radiate out from a central concept rather than list in sequence.

## Purpose

Linear notes and lists force ideas into an order before you actually know the relationships between them. A mind map defers that ordering — you place a keyword near where it conceptually belongs, and the structure of relationships (what's close to what, what branches off what) can be reworked as you go, which makes it a better tool for exploring a topic than for recording one you've already understood.

## When to use

- You're starting from one topic and don't yet know its natural subtopics — kicking off research, structuring a talk, unpacking a vague problem
- You want to see relationships between ideas spatially, not just as a flat list
- The output needs to stay flexible and reorganizable as you add more branches
- You're working alone or with a small group and want a fast capture method that doesn't require deciding structure up front

## How to do it

1. Write or draw the central topic in the middle of the page or canvas.
2. Draw a small number of main branches out from the center — the first-level categories the topic breaks into.
3. Off each main branch, add sub-branches as specific ideas, examples, or questions occur to you — keep each node to a word or short phrase, not a sentence.
4. Use color, icons, or line weight to mark relationships or priority as patterns emerge; the visual distinction is doing real work, leaving linear language for a spatial layout that actually shows structure.
5. Keep working outward and revising: mind mapping is meant to be non-linear, so move back to an earlier branch and add to it whenever a later branch reminds you of something relevant.
6. When the map feels complete, use it as an outline — a linear document or presentation can be built directly from a good map's branch order.

## Common mistakes

- **Writing full sentences in nodes** — this defeats the purpose; a node should be a single word or short phrase that acts as a memory trigger, not a stored complete thought.
- **Forcing branches into a rigid tree when the real relationships are cross-cutting** — if two branches from different parts of the map are actually deeply related, a strict single-parent tree hides that; consider a concept map instead, which explicitly labels relationships between any two nodes, not just parent-child.
- **Treating the map itself as the deliverable** — a mind map is almost always a thinking tool for one person or a small group, not something to hand to a stakeholder as a finished artifact; translate it into prose, a deck, or a structured doc before sharing widely.
- **Over-designing it before the ideas are settled** — spending time on layout and color while still generating content slows down the exact freeform exploration the method is for.

## Tips

Start with a completely blank page rather than a template — the freedom to branch anywhere is most of the value, and a rigid pre-built structure fights it. Branching, radial note-taking predates the modern popularization of "mind mapping" by centuries — treat it as a well-packaged version of an old idea, and don't be precious about following any specific rule set (colors, curved lines, one word per branch) if a looser version works better for you.

## Using AI

**Where it helps**
- Turning a completed hand-drawn or freeform map into a clean, presentable diagram after the thinking is done.
- Suggesting additional sub-branches for a topic you've already started mapping, as raw material to accept, reject, or rework — not as the map itself.

**Where it fails**
- Generating the whole map from a prompt with no human branching decisions. The value of mind mapping comes from the mapper's own associative process — which subtopic feels closer to which, what surprised you enough to add a new branch — and a model's neatly pre-structured version skips exactly that process while looking more finished than a real working map ever is.
