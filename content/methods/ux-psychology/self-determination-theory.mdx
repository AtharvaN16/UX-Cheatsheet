## What is it

Human motivation depends on fulfilling three basic psychological needs: Autonomy, Competence, and Relatedness.

## Why it matters

Extrinsic gamification (badges, leaderboards) produces short-term engagement spikes followed by habit decay. By designing experiences that empower users to choose their own paths (**Autonomy**), master valuable skills (**Competence**), and connect meaningfully with others (**Relatedness**), products build self-driven, long-term retention.

## Key ideas

- **Autonomy**: The need to feel in control of one's own life, choices, and actions.
- **Competence**: The need to feel effective, experience skill progression, and achieve mastery.
- **Relatedness**: The need to feel connected, valued, and belonging within a community.
- **The Overjustification Effect**: Offering extrinsic rewards for an inherently enjoyable task can destroy intrinsic motivation.

## How it works

The Intrinsic Motivation Triad:

```
                  ┌────────────────────────┐
                  │      AUTONOMY (Choice) │
                  └───────────┬────────────┘
                              │
                              ▼
  ┌───────────────────────────┴───────────────────────────┐
  │ INTRINSIC MOTIVATION & DEEP PRODUCT ENGAGEMENT         │
  └───────────────────────────┬───────────────────────────┘
                              ▲
            ┌─────────────────┴─────────────────┐
            │                                   │
┌───────────┴────────────┐             ┌────────┴───────────────┐
│  COMPETENCE (Mastery)  │             │ RELATEDNESS (Belonging)│
└────────────────────────┘             └────────────────────────┘
```

## Example

1. **Duolingo Learning Experience**: Fulfills **Competence** through bite-sized skill trees and progress strength meters; fulfills **Autonomy** by allowing users to choose daily goal intensity; fulfills **Relatedness** through friend quest challenges.
2. **Figma Community**: Fulfills **Autonomy** by letting designers structure canvas files freely; fulfills **Competence** through vector tool mastery; fulfills **Relatedness** via publishing community plugins and templates.

## Application

- **Support Autonomy**: Provide flexible customization options, non-linear workflows, and clear skip controls during onboarding.
- **Build Competence**: Show visual skill progress meters, provide constructive feedback, and introduce progressive complexity.
- **Foster Relatedness**: Enable multiplayer collaboration, social sharing, and community forum connections.

## Limitations

- **Extrinsic Necessity**: Routine compliance or administrative tasks (e.g., expense reporting) have zero intrinsic appeal; extrinsic incentives remain necessary.
- **Autonomy vs Structure Balance**: Excessive autonomy without structural guidance causes onboarding confusion.

## Common misconceptions

- **"Gamification points create loyal users"**: Extrinsic points without intrinsic autonomy and competence build fragile, superficial engagement.
- **"Autonomy means zero guidance"**: Users need clear scaffolding to build competence before they can enjoy true autonomy.

## Using AI

**Where it helps**
- Analyzing user telemetry to assess whether feature usage is driven by intrinsic mastery versus extrinsic notification prompts.
- Personalizing learning path recommendations to match individual user competence levels.

**Where it fails**
- Simulating genuine human feelings of community belonging and personal autonomy.
