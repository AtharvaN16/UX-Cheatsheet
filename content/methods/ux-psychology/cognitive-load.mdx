## What is it

The total amount of mental processing effort being used in a user's working memory while attempting to complete a task.

## Why it matters

Humans have finite mental bandwidth. Excessive cognitive load leads to user frustration, high error rates, decision fatigue, and task abandonment.

## Key ideas

- **Intrinsic Load**: The inherent difficulty of the task itself (e.g., calculating tax returns).
- **Extraneous Load**: Wasteful mental effort generated by poor UI layout, confusing copy, or ambiguous navigation.
- **Germane Load**: Constructive mental processing dedicated to learning and building long-term mental models.

## How it works

Cognitive Load allocation formula:

$$\text{Total Cognitive Load} = \text{Intrinsic Load} + \text{Extraneous Load} + \text{Germane Load}$$

UX design aims to **eliminate Extraneous Load** so that working memory capacity can be spent on Intrinsic problem solving and Germane learning.

## Example

Requiring a user to memorize a promo code on page 1 and manually type it into an un-formatted field on page 3 imposes unnecessary Extraneous Load. Auto-applying the code at checkout eliminates that extraneous mental effort completely.

## Application

- **Eliminate Visual Clutter**: Remove non-essential UI elements, redundant decorative graphics, and competing visual callouts.
- **Offload Memory to the Interface**: Display relevant context (e.g., selected plan details, total price) alongside decisions rather than expecting users to remember previous screens.
- **Provide Clear Feedback**: Instantly signal system state so users don't wonder if their click registered.

## Limitations

- **Cannot Be Measured Directly with Automated Tools**: Cognitive load is a subjective psychological state, evaluated best via qualitative think-aloud studies or standardized rating scales (e.g., NASA-TLX).
- **Some Intrinsic Load Is Unavoidable**: Complex domain tasks (e.g., medical diagnostics or code debugging) inherently require high cognitive effort.

## Common misconceptions

- **"All cognitive load is bad"**: Germane load (learning useful patterns) builds skill and mastery. The goal is to eliminate *extraneous* load, not all mental engagement.
- **"Simple UI always means fewer features"**: Simple UI means well-structured information architecture and clear visual hierarchy, not feature stripping.

## Using AI

**Where it helps**
- Identifying redundant form steps or visual distractions in design files.
- Rewriting dense technical instructions into concise, scannable microcopy.

**Where it fails**
- Measuring real user emotional fatigue or stress levels during high-stakes task execution.
